# Contributing

Intelligence Sync is archived at its final vendored release. New features, adapters, bug fixes and documentation work belong in [ainova-systems/intelligence](https://github.com/ainova-systems/intelligence).

Please use the successor repository for:

- bug reports and security-relevant behavior;
- feature and adapter requests;
- CLI, engine, package and documentation changes;
- pull requests.

This repository remains available only so existing vendored projects can reach the supported CLI conversion boundary. Its historical implementation and documentation are frozen.

By contributing to the successor project, you agree that your contributions are licensed under its MIT License.
